# Emmanuel Sagarino — Personal Portfolio

My personal portfolio website. I'm a 4th year BSIT student at Jose Rizal University and an aspiring Software Developer.

**Live site:** https://emmanuel-sagarino-personal-portfoli.vercel.app/

## Features

- About, skills, projects, experience, and education sections
- Live GitHub contribution graph
- Light and dark mode toggle (remembers your choice)
- Responsive layout for desktop and mobile
- SEO setup: meta tags, Open Graph, structured data, sitemap, and robots.txt

## Built with

HTML, CSS, and JavaScript, with no framework or build step. Deployed on Vercel.

## Project structure

```
portfolio-project/
├── index.html      # page content
├── css/style.css   # styles, including light/dark themes
├── js/script.js    # theme toggle, navigation, scroll effects, contact form
├── assets/         # profile photo and favicon
├── robots.txt
└── sitemap.xml
```

## Run locally

Open the folder in VS Code and use the Live Server extension, or open `index.html` directly in a browser.
